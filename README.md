## JournalGUI
Converts raw NTFS change logs into a clean, chronological timeline of file activities

## BeeHive
Translates and displays data from some of major Windows Registry hives as entries, specifically **Amcache**, **BAM**, **UserAssist**, **USBstore**, **OpenSave** as of now

## Prefetcher
Views prefetch files to display detailed info about them, you can view loaded files by **Right-Clicking** an entry. You can also view java's deleted entries by clicking **deleted entries** button

## DownloadedSource
Reads browsers' local database to display downloads history even after clearing it manually. You can also view the website from which a file has come

## WLviewer
Reads and displays windows logs from all major categories (application, security, system). making it easy to view someone's malicious activities without having to jump back and forth 

## AltsFinder
Not for finding cheats, but rather to find someone's Minecraft alternate accounts. it performs simple checks on game files
